# Response template specification (bidder-facing workbook)

Input cells are shaded and unlocked; formula and label cells are protected. Every sheet carries the event reference and bidder name in its header.

## Instructions
Event reference, response deadline with time zone, how to complete each sheet, file naming rule, contact point, statement that totals are calculated automatically and must not be overwritten.

## Bidder_Details
Legal entity name | Registration number | Country of registration | Registered address | Parent company | Contact name and role | Contact email | Bid validity (days) | Currency of bid

## Mandatory_Compliance
Req ID | Requirement | Evidence required | Compliant (Yes/No) | Evidence reference (document and page) | Comment

## Scored_Responses
Req ID | Criterion | Requirement | Evidence expected | Response (text) | Supporting document reference | Word limit

## Pricing_Schedule
| Column | Content |
|---|---|
| Line ID | Fixed by buyer |
| Description | Fixed by buyer |
| Unit of measure | Fixed by buyer |
| Charge type | One-off / Recurring monthly / Recurring annual / Per unit |
| Indicative annual volume | Fixed by buyer, with period and source in the header |
| Tier 1 upper bound | Bidder entry, if tiered |
| Tier 1 unit price | Bidder entry |
| Tier 2 unit price | Bidder entry, if tiered |
| Tier basis | Incremental or all-units, bidder selects |
| Annual cost | Formula from volume and tiers |
| Term cost | Formula = annual cost x term years, or one-off amount |
| Price validity | Bidder entry |
| Indexation offered | Bidder entry: none, fixed percent, or named index and cap |
| Assumptions | Bidder entry |

Summary block: total one-off, total recurring per year, total over base term, total including option years, all as formulas. Currency fixed to the bid currency stated in Bidder_Details.

## Assumptions_Exceptions
Ref | Document and section the exception relates to | Exception or assumption | Commercial impact stated by bidder | Mandatory or preference

## Declarations
Conflict of interest, non-collusion, acceptance of instructions, authority to sign, date and signatory name and role.
