# Default due-diligence checklist

Use only when the user's onboarding policy is not supplied, and label the output "Default checklist - confirm against policy". Risk tier decides which items apply; record `Not applicable` with a reason rather than deleting rows.

## Tiering guide (confirm with the user's policy)

| Tier | Typical profile |
|---|---|
| Tier 1 | Access to personal or confidential data, on-site work, critical supply, regulated service, or annual spend above the user's high-value threshold |
| Tier 2 | Moderate spend, no sensitive data access, replaceable within months |
| Tier 3 | Low spend, catalogue or one-off goods, no data or site access |

## Financial ratio definitions

| Ratio | Formula | Statement lines |
|---|---|---|
| Current ratio | Current assets / current liabilities | Balance sheet |
| Quick ratio | (Current assets - inventory) / current liabilities | Balance sheet |
| Net debt / EBITDA | (Short- and long-term borrowings + lease liabilities if policy includes them - cash) / EBITDA | Balance sheet, income statement, notes |
| Gearing | Total borrowings / (total borrowings + equity) | Balance sheet |
| Interest cover | EBIT / interest expense | Income statement |
| EBITDA margin | EBITDA / revenue | Income statement |
| Revenue growth | Revenue current year / revenue prior year - 1 | Income statement |
| Dependency | Expected annual spend with supplier / supplier revenue | Sourcing requirement; income statement |

If EBITDA is not reported, compute EBIT + depreciation + amortization from the statements and label it computed. Negative EBITDA makes net debt / EBITDA not meaningful; report `Not meaningful - negative EBITDA` and flag.
