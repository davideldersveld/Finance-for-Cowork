# Negotiation grid — definitions and calculations

## Positions sheet columns

| Column | Definition |
|---|---|
| Variable | One negotiable term (unit price, annual fee, term length, volume commitment, payment terms, service level, service credit cap, indexation cap, rebate, delivery terms) |
| Priority | Must have / Should have / Nice to have |
| Unit | For example USD per unit, days, percent, months |
| Current | Today's contractual value with clause or invoice reference |
| Opening | First position stated; ambitious but defensible with cited evidence |
| Target | Realistic, evidence-supported outcome |
| Walk-away | Least favourable acceptable value; derived from the best alternative |
| Value per unit move | Annual value to the buyer of one unit of movement |
| Value current to target | (Current - target) x volume, or equivalent |
| Evidence | Source document, sheet and cell, or page |
| Status label | Evidenced / Benchmark-based / Assumption / Hypothesis |
| Tradeable for | Variables the team will accept movement on in exchange |
| Approver above | Person whose approval is needed beyond the lead's authority |

## Standard calculations

| Item | Formula |
|---|---|
| Effective alternative price | Alternative unit price + switching costs / (annual units x alternative term years) |
| Value of 1 percent price | Annual spend x 0.01 |
| Value of price move per unit | Price change x annual volume |
| Payment-term value to buyer | Annual spend x (new days - current days) / 365 x cost of capital (from profile or user) |
| Cost-justified increase from one input | Input cost change percent x input's share of price (share evidenced by the supplier's cost breakdown) |
| Volume commitment risk | (Committed volume - forecast low case volume) x unit price, where the forecast is supplied |
| Zone of possible agreement (price) | Between estimated supplier floor (Hypothesis) and buyer walk-away; if the estimated floor is above walk-away, no zone exists and the plan shifts to scope or specification levers |

## Concession plan columns

Step | Concession offered | Condition requested in return | Value given (annual) | Value received (annual) | Net | Cumulative distance from target | Approval needed (Yes/No)

Rules: each concession is conditional; step sizes decrease; never move two variables at once without a return; stop and consult the approver when cumulative concessions reach the lead's authority.

## Arguments sheet columns

Supplier argument | Likely evidence they will cite | Our evidence | Response | Data to request | Trade if the argument is valid | Owner in the room

## Post-meeting record

Date | Attendees | Offers made by each side | Concessions given and received | Open points | Agreed next steps and owners | Deviation from plan and approver who authorized it
