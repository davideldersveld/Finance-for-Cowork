# Position paper template and citation rules

Use this as the default structure when the user has no house template. If a house template exists, map these elements onto it and list any element the template lacks as an addition at the end.

## Header block

| Field | Content |
|---|---|
| Entity | Legal entity or consolidated group as named in the Finance Profile |
| Framework | US GAAP (registrant / non-registrant) or IFRS as adopted (state jurisdiction if relevant) |
| Period | Fiscal period or transaction date addressed |
| Issue title | One line, neutral wording (no conclusion in the title) |
| Prepared by | The user (name and role) |
| Reviewed by | Blank until the user records a reviewer |
| Version and date | v0.1 onwards; increment on every revision |
| Status | Draft for controller review / Draft for auditor discussion |

## Section guidance

**Purpose and summary conclusion.** Two to five sentences per issue: the question, the answer, the strength label and the headline effect. A reader who stops here must not be misled.

**Background and facts.** Numbered facts, chronological where possible. One fact per row.

| No. | Fact | Source | Evidence type |
|---|---|---|---|
| F1 | Master agreement executed 12 March 2026 | Agreement p.1, signature page | Document |
| F2 | Customer cannot cancel without penalty after month 3 | Agreement clause 14.2 | Document |
| F3 | Sales team expects 80% renewal | Email from regional VP, 2 May 2026 | Management representation - to be evidenced |

Evidence types: Document, Ledger or system record, Management representation - to be evidenced, Assumed (only where the user approves the assumption; state it).

**Issues.** Number them I1, I2. State whether each is recognition, measurement, presentation or disclosure. Note interdependencies (for example I2 only arises if I1 concludes there is a lease).

**Applicable guidance.** One row per citation.

| Citation | What it addresses | Retrieval status |
|---|---|---|
| ASC 810-10-15-14 | Characteristics of a variable interest entity | Retrieved from user's research library, 3 Oct 2026 |
| IFRS 10.7 | Elements of control | Text not retrieved - verify |

Retrieval status values: Retrieved (source and date), Supplied by user, Text not retrieved - verify.

**Analysis.** For each issue and alternative:

1. View (the accounting result in one sentence).
2. Guidance supporting the view, cited by paragraph.
3. Facts supporting (fact numbers).
4. Facts against (fact numbers) and guidance that cuts the other way.
5. Quantified effect (reference to the appendix calculation).

Then an evaluation paragraph explaining which view carries more weight and why, referring to fact numbers and paragraphs, not adjectives.

**Conclusion.** Restate each issue's answer and strength label. If `Unresolved`, list the specific evidence or guidance that would resolve it.

**Financial statement impact.** Show effect by statement and line item for the current period and each comparative period presented, plus any cumulative effect on opening retained earnings. State currency, units and basis. If the conclusion changes previously issued numbers, state that an error evaluation under ASC 250 or IAS 8 is needed and that materiality is assessed by management, not by this paper.

**Disclosure impact.** One row per requirement: requirement, citation, proposed note or MD&A location, draft wording status (Not drafted / Drafted in appendix).

**Open items.** Question, why it matters (issue number), owner, needed-by date.

## Citation formats

- US GAAP Codification: `ASC 606-10-25-19` (topic-subtopic-section-paragraph). Section numbers: 05 overview, 15 scope, 20 glossary, 25 recognition, 30 initial measurement, 35 subsequent measurement, 40 derecognition, 45 other presentation, 50 disclosure, 55 implementation guidance, 65 transition.
- SEC material: `SAB Topic 13`, `Regulation S-X Rule 5-02`, `Regulation S-K Item 303`.
- IFRS: `IFRS 15.22`, `IAS 36.12(d)`, `IFRS 16.B34` for application guidance, `IFRS 9.BC5.10` for basis for conclusions (non-authoritative; label it).
- Interpretations and agenda decisions: name, date of publication and topic.
- Non-authoritative sources: name, edition and section, labelled "non-authoritative".

## Quoting rule

Quote at most the phrase or single sentence that carries the point, in quotation marks, with the paragraph reference. Summarize everything else in your own words. Never reconstruct guidance text from memory.

## Strength labels

| Label | Use when |
|---|---|
| Supported | One answer is clearly required; no credible alternative after reading the guidance |
| Judgemental - supported | At least one credible alternative; weight of guidance and evidenced facts favours the conclusion |
| Unresolved | Facts missing, documents missing, or guidance conflicts so no conclusion is responsible |

## Pre-delivery checklist

- Every fact row has a source and evidence type.
- Every citation has a paragraph and a retrieval status.
- Every amount recomputes in code and ties to its source schedule; entries balance.
- Conclusion, illustrative entries, impact table and disclosure table are mutually consistent.
- Header reads "DRAFT - for controller and auditor review" on every page.
